# EF2 feedback architecture study

Status: **BLOCKED** for equivalent 32-lane architecture and its PPA. Baseline source SHA `67d68abb402f9bb2c9a87a43a99f46955acfe9d9`, Vivado 2026.1 build 6511674. Routed DCP and Worst-20 are `runs/vcu118_ppa_research_01/ef2/routed.dcp`, `setup_worst20.rpt` and `hold_worst20.rpt`.

The core-clock path from pre-DSM FIFO sample register to EF2 error state is 101.701 ns, 409 logic levels and 190 CARRY8; 42.537 ns is logic and 59.164 ns routing. The reference is a 32-sample serially unrolled second-order error-feedback recurrence. Any grouping must preserve every signed quantizer decision, saturating residue, update order and earliest-lane-first packing. Registering arbitrary groups would change the recurrence or II; false or multicycle exceptions do not resolve this one-cycle dependence.

The existing pair-lookahead implementation speculates the next quantizer outcome, selects the corresponding exact next-state transfer and is disabled in official product defaults. VC Formal V-2023.12-SP2 established the two-lane scoped relational proof (7 assertions, 4 covers); 32-lane full-core VCF left output/state equivalence inconclusive, despite a complete 32-lane 4,096-cycle simulation miter and matching full-QAM PA files. New 4-lane and 8-lane harnesses instantiate reference and lookahead cores with arbitrary operands, valid/ready and common declared reset. The 4-lane run `runs/ef2_4lane_formal_01/` has zero black boxes, 4 of 7 assertions proven and 3 inconclusive; four covers hit. The 8-lane run `runs/ef2_8lane_formal_01/` also finished with 4 proven and 3 inconclusive assertions, all 4 covers reached and zero black boxes. Do not claim PASS unless each full assertion list is proven with zero black boxes. Independent-reset behavior and physical PPA remain separate obligations.

Formal sources: `dv/uvm/formal/thermo5_ef2_{4,8,32}lane_equiv_harness.sv`, Tcl `research/vcu118_arch/formal_ef2_small_lane.tcl`.
