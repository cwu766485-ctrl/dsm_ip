# Live AXIS-to-GTY integration

Status: **FAIL** for live attempts 01 and 02 because input underflow was asserted. Despite that failure, attempt 02 established a limited digital payload result through the real live chain. Source baseline `773983f29158edc8aff64aab5ce5fc7b54d15e6b` plus research testbench; Vivado 2026.1 build 6511674 and GT Wizard 14.000 Gb/s nominal raw mode.

`dv/verif/integration/vcu118_arch/tb_vcu118_live_axis_gty.sv` connects canonical runtime product RTL, AXIS input, AXI-Lite MASH selection, PA handshake and the research complete-frame buffer to two GTY TX/RX lanes. The GTY TXUSRCLK2 drives the core and buffer, avoiding an unmodeled clock boundary. It compares actual frontend/PA outputs and recovered GT serial bits against the preserved 5,264-word independent MASH golden. The test introduces source bubbles and STOP during an open frame; it checks frame markers, configuration ID, underflow and serial alignment. The buffer epoch input is synthetic zero because the product interface does not expose an epoch. Reset/restart/relock across multiple frames is not yet covered by this bench.

Live XSim attempt 01 checked 5,264 PA/prefill words but failed a combined status check before serial comparison (`runs/live_axis_gty_01/`). In attempt 02 the complete actual chain fed the GTY model, including source bubbles and STOP during frame. All 5,264 PA/prefill words matched the independent golden; both GTY serial TX and PMA loopback matched 336,896 bits per lane and observed skew was zero. The final status was `drain=1 underflow=1 protocol=0`, so the overall stress test **FAILS** (`runs/live_axis_gty_02/project/gty_sim.sim/sim_1/behav/xsim/simulate.log`). The serial-bit receiver gives EVM 2.551442%, SNDR 31.864285 dB, 15/37,376 uncoded errors (`runs/live_axis_gty_receiver_02/metrics.json`); the separate Welch PSD gives combined adjacent proxy -16.314892 dBc and lower/upper -19.254889/-19.396653 dBc (`runs/live_axis_gty_psd_02/`). This digital proxy is not RF ACLR.

The AXIS FIFO has 16 entries and starts after a two-beat prefill. Its nominal source capacity is 125 MHz × 14 = 1.75 Gsample/s, equal to the core consumption 218.75 MHz × 8 = 1.75 Gsample/s. Therefore sustained periodic input bubbles cannot be absorbed indefinitely by this finite FIFO; the observed flag cannot be dismissed merely because the post-MASH frame buffer reproduced the correct bitstream. The exact assertion cycle and whether any additional behavior contributes are still under investigation. A separate no-injected-bubble control (`sim_live_axis_gty_contiguous.tcl`, `runs/live_axis_gty_03/`) is running; it does not replace the failed stress case. Complete-frame output buffering alone does not remove the upstream underflow flag or prove an unlimited input-stall contract.

A research-only single-bank input frame prefill candidate `research/vcu118_arch/thermo5_axis_frame_prefill.sv` collects up to 3,008 AXIS beats before replaying them to the product at the original AXIS clock. It aims to absorb this finite-frame bubble pattern before core consumption begins; it does not guarantee arbitrary-length frames, unbounded stalls or back-to-back throughput. Candidate `sim_live_axis_gty_axis_prefill.tcl` preserves the stressed source pattern and Golden and is running in `runs/live_axis_gty_04/`. Independent unit tests passed source bubbles and output stall (`runs/axis_frame_prefill_unit_01/`), plus reset discarding a partial frame and oversized-frame fault (`runs/axis_frame_prefill_reset_01/`). Its storage is about 3,008 × (2 × 14 × 16 + 16 + 2) = 1,401,728 bits before implementation overhead; synthesis and PPA are NOT_RUN. It is not connected to the production top or the PPA cases.

The epoch input is synthetic zero because the product interface lacks an epoch output. Multi-frame STOP/restart, independent resets/relock and board-level alignment remain NOT_RUN. Execute with an unused output directory and explicit Vivado `bin` PATH. Require the final absence of fatal messages as well as the TX/RX bit-true markers; Vivado's `GTY_SIM_RUN_FINISHED` is not sufficient.

Prior separate PA replay evidence: `runs/gty_pa_replay_04/project/gty_sim.sim/sim_1/behav/xsim/simulate.log` and `runs/gty_serial_receiver_01/metrics.json`. Hardware RF and ACLR: **NOT_MEASURED**. Clock/reset/GTY board and PVT alignment remain open.
