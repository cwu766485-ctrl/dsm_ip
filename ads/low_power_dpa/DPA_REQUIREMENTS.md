# DPA Simulation Endpoint Requirements

## Scope

This document defines the optional DPA simulation endpoint used to exercise
the DPD algorithm. It is not a foundry implementation specification and does
not establish a measured RF power, PAE, silicon, or production claim.

## Project Priority

The DPA exists to provide gain error, nonlinear compression, short memory,
filtering, and observation noise. DPD is the main engineering subject. The
MATLAB behavioral endpoint is sufficient for the primary milestone;
ADS/PDK results are supporting evidence only.

The circuit-level DPA used for system results may be a generic finite-loss
H-bridge. A process PDK is not required unless a process-specific transistor
claim is needed. The generic model uses declared assumptions and is reported as
a numerical or ADS circuit trend, not a fabrication result.

## Frozen Baseline

| Item | Value |
|---|---:|
| Digital input | Historical LPDSM2 one-bit `rf_bit`; regenerate from BP EFDSM2 for current-SKU work |
| Digital sample rate | 100 MHz |
| Nominal IF center | 25 MHz |
| Generic-model supply | 3.3 V |
| Switching topology | Differential H-bridge with 1 ns non-overlap |
| Reconstruction | Series LC branch, nominal 25 MHz center |
| Current measurement plane | 100 ohm differential pre-balun load |
| Long validation window | 4096 bits, 40.96 us |
| ADS transient maximum step | 5 ps |
| MATLAB feedback export | 1 GHz uniformly sampled voltage and interval-average current |

The source waveform is generated by the project MATLAB LPDSM2 path. The ADS
generator derives four `VtPWL` gate controls from each `rf_bit` transition,
then enforces all-gates-off dead time before enabling the next H-bridge
diagonal. The ideal switch model is supplemented with explicit rail clamps so
the dead-time bridge-node behavior is bounded.

## Optional DPA Demonstrator Target

The following target is retained only as a simple circuit-demonstrator
reference. It is not required for the DPD milestone and is not certification
against an LTE,
NR, Wi-Fi, or other external radio standard. A future standard-specific
release must replace the occupied-bandwidth and ACLR measurement definitions
through a documented change.

| Item | V1 target |
|---|---:|
| Final output port | 50 ohm single-ended after balun/matching |
| Nominal output power | 0 dBm at 25 MHz IF |
| Occupied bandwidth | 500 kHz |
| Modulation-quality target | 256-QAM EVM <= 3.5% after coherent recovery |
| Adjacent-channel target | ACLR <= -45 dBc under the final defined mask |
| Supply range | 1.2 V +/- 5% |
| Ambient-temperature range | 0 to 85 degrees C |
| Bridge/load transformation | 100 ohm differential to 50 ohm single-ended, 2:1 impedance ratio |
| Dead time | 1 ns nominal; 0.5 ns to 2 ns design sweep |

The 100 ohm differential pre-balun plane remains the circuit debug plane.
The final compliant measurement plane is the 50 ohm single-ended output after
the balun and matching network. A 1:1 voltage balun does not transform 100
ohm differential to 50 ohm single-ended; the required nominal impedance ratio
is 2:1, corresponding to an ideal turns ratio of sqrt(2):1 before parasitic
and loss optimization.

2. Allowed supply voltage, device reliability limits, and available corners.
3. RF/thick-oxide MOS options, passive models, and recommended layout rules.

Freeze the exact process, device flavor, corner set, and model revision in a
restricted design record. Do not add confidential PDK files or vendor model

A separate TT/25 C/1.2 V gate-driver compatibility run inserted two PDK CMOS

The PDK-driver switch core also completed a 256-bit MATLAB LPDSM2 `rf_bit`
PWL transient. It had zero overlap samples and exported a 1 GHz uniform

## Circuit-Endpoint DPD Handoff

The existing behavioral LPDSM2 DPA+BPF release gate accepted a Q1.15/Q2.14
four-tap C1/C3/C5 coefficient package. The ADS PWL pair exporter reads only
that accepted release and emits separate no-DPD and candidate bitstreams. The
default no-DPD PWL remains identical to the checked LPDSM2 export over 256
samples; the candidate changes 126 bits with no fixed-point saturation or
drive limiting.

At the selected TT PDK-driver/passive proxy endpoint, both 256-bit runs had
zero leg overlap. No-DPD measured -3.85 dBm, 1.48 mW DC, and 27.88% efficiency
trend; the candidate measured -4.39 dBm, 1.27 mW DC, and 28.71%. The short
window's spectral values are trend proxies only. They do not establish EVM,
SNDR, ACLR, or DPD improvement. The required next loop is ADS output
observation -> gain/phase/delay alignment -> memory-PA identification ->
coefficient retraining -> a repeated PWL pair comparison.

## Spectrum Protocol

The current automated spectrum report is intended for design trend comparison:

- In-band proxy: 25 MHz +/- 0.25 MHz.
- Adjacent proxies: offsets from 0.50 MHz to 2.50 MHz on either side.
- Third-harmonic proxy: 75 MHz +/- 0.25 MHz.
- A 1 GHz resampling grid and Hann-window periodogram are used after a 4 us
  settling interval for the 4096-bit run.

These quantities are not ACLR. The narrowband modulated waveform has not been
coherently demodulated, no standard channel mask has been selected, and no
physical 50 ohm output plane exists. The current adjacent proxies of about
-1.6 dBc and -2.1 dBc show that the simple 5 MHz LC branch is insufficient as
a final output filter.

## Deferred Circuit Work

The following product-level items are intentionally deferred and are outside
the current DPD deliverable:

1. Confirm or revise the V1 output-power, bandwidth, and EVM/ACLR targets
   above for the intended radio standard.
2. Freeze the restricted local process/PDK revision and RF-MOS device option.
3. Select a balun or transformer implementation and package/PCB reference
   plane at the final 50 ohm output.

Without these, circuit sizing would be exploratory only. No such sizing work
is required to continue the behavioral DPD experiments.

## Optional Circuit Tasks

### Generic Finite-Loss 3.3 V Efficiency Model

The PDK-independent numerical screen is
`ads/scripts/run_generic_dpa_loss_model.py`. It uses the actual checked
4096-sample LPDSM2 one-bit input, a 1 GHz series-RLC time-domain solver, and
explicit all-off dead time. It preserves the 25 MHz `3.18 uH/12.7 pF` series
LC network and a 100 ohm differential bridge-side load. It includes declared
switch conduction, LC, switch-node charging, and gate-drive losses. The three
screened candidates are:

| Candidate | RON | Node capacitance |
|---|---:|---:|
| `low_loss` | 0.10 ohm | 0.5 pF |
| `balanced` | 0.20 ohm | 1.0 pF |
| `conservative` | 0.50 ohm | 2.0 pF |

The 3.3 V `low_loss` candidate is the generic-model winner: `0.10 ohm` switch
resistance, `0.5 pF` switch-node capacitance, `0.1 pF` gate capacitance per
control, and `0.20 ohm` LC series loss. It resonates at `25.044 MHz`, produces
`13.388 mW` (`11.267 dBm`) at the 100 ohm differential plane, draws
`14.218 mW` DC, and yields a `94.165%` finite-loss efficiency trend. Its loss
breakdown is `0.054 mW` conduction, `0.554 mW` switching-node charging, and
`0.222 mW` gate drive. The balanced and conservative sensitivity points yield
`89.109%` and `81.339%`, respectively. These are numerical-model results,
not ADS, PDK, layout, or silicon evidence.

Run the reproducible screen with:

```powershell
python .\ads\scripts\run_generic_dpa_loss_model.py
```

The output CSV has the common `time_s,vout_v,ivdd_a` contract at 1 GHz. Feed
it into `extract_ads_complex_feedback.py` (despite its retained filename) for
25 MHz downconversion and complex-feedback identification. A 5 V sweep is
allowed for a generic higher-power sensitivity study through `--vdd 5`, but it
is a different supply-domain assumption, not an automatic replacement for the
3.3 V baseline.

The generic numerical efficiency pre-screen is complete for the stated
assumptions. It does not close the ADS circuit or DPD endpoint. Any future
circuit refinement must hold the source waveform, measurement plane, PWL
length, and dead-time contract fixed while sweeping the following parameters:

1. Set the first capacitor candidate to `C_BPF=9.7 pF`, because `L_BPF=3.18
   uH` and `L_PRI=1.0 uH` are in the same series path. The former `12.7 pF`
   point is near 21.84 MHz rather than 25 MHz.
2. Sweep `C_BPF`, RF-MOS fingers, driver fingers, and dead time jointly. Rank
   only zero-overlap cases by Pout, Pdc, efficiency trend, output peak, and
   peak supply current.
3. Run the selected point with a sufficiently long DSM PWL waveform and export
   `time_s,vout_v,ivdd_a` at the same 50 ohm plane.

The current 1.2 V supply is a verified condition for the selected local RF-MOS
deck. Do not change it to 3.3 V or 5 V without a validated thick-oxide or
high-voltage device option, gate-driver supply domain, reliability limits, and
matching-network redesign. Changing only the netlist voltage would not be a
valid higher-power DPA simulation.

## Unified DPA-to-DPD Measurement Contract

For a circuit-endpoint DPD claim, evidence must be generated from ADS output
instead of from an unrelated normalized behavioral PA. The generic numerical
loss model is only an efficiency pre-screen and is not an ADS DPD endpoint:

```text
MATLAB no-DPD / memoryless DPD / memory-polynomial DPD + LPDSM2 -> rf_bit CSV
  -> same frozen ADS DPA transient for each mode
  -> time_s,vout_v,ivdd_a -> coherent 25 MHz downconversion and alignment
  -> complex feedback -> EVM/SNDR/ACLR proxy and PA-model identification
```

At the same ADS measurement plane, report `Pout=mean(vout_v^2/50)`,
`Pdc=VDD*mean(ivdd_a)`, efficiency `Pout/Pdc`, output peak, EVM, SNDR, and the
explicitly defined spectrum/ACLR proxy. These form one endpoint table for
no-DPD, memoryless DPD, memory-polynomial DPD, and AI-seeded bounded search.
Each mode needs a fresh long ADS run. The short existing pair is insufficient
for a release-quality EVM/ACLR result; it validates only the handoff contract.

The ADS-DPA DPD procedure is deliberately sequential:

1. Run the long no-DPD PWL in ADS and export its observation.
2. Use the observation to select the DPA behavioral form and train initial
   memoryless and memory-polynomial coefficient packages offline.
3. Export separate long PWL inputs for the trained memoryless and
   memory-polynomial packages, then run both through the unchanged ADS DPA.
4. Evaluate all three ADS observations against the same saved transmit
   reference. Report EVM, SNDR, ACLR proxy, Pout, Pdc, efficiency, clipping,
   saturation, stall, and error counts in one table.

The existing behavioral DPD coefficient tables are bootstrap candidates only;
they cannot be reported as ADS-DPA-trained until this procedure completes.

1. Use the selected PVT baseline to optimize RF-MOS fingers and PDK gate-driver
   sizing against the 0 dBm target without exceeding the current budget.
2. Replace the estimated transformer/loss proxy with an available balun/matching
   implementation, including passive Q and package/PCB parasitics.
3. Sweep RF-MOS fingers, output capacitance, and filter Q against
   the selected power and spectrum requirements.
4. Identify a memory PA from the exported circuit observation and retrain the
   DPD coefficients before comparing no-DPD, polynomial-DPD, and Memory-Poly
   DPD at the same electrical endpoint.

## 25 MHz Retuning and Calibration Boundary

The initial pre-layout network is not an optimized DPA output match. `L_BPF`
and `L_PRI` are both in the series current path, so `L_BPF=3.18 uH`,
`L_PRI=1.0 uH`, and `C_BPF=12.7 pF` have a first-order resonance of
approximately 21.84 MHz. A 25 MHz starting estimate for that 4.18 uH total
inductance is `C_BPF=9.70 pF`. This is a starting point only; the selected
capacitor, RF-MOS size, driver size, dead time, and transformer/match must be
screened at the same 50 ohm measurement plane and then rerun across PVT.

The `run_tsmc40_dpa_25mhz_screen.py` ranking uses the following pre-layout
criteria:

- no high-side/low-side leg overlap;
- minimum error to the 0 dBm nominal target;
- maximum DC-to-load efficiency trend subject to a declared peak-current limit.

The screen does not claim DPA PAE or final efficiency. A physical balun,
matching/filter network, package parasitics, and an RF output measurement are
still required before circuit closure.

For system research, the MATLAB `run_dpa_ai_seeded_calibration` experiment
provides a separate behavioral feedback loop. It trains a ridge-regression
initial-point predictor from observation metrics, then requires a bounded
Q2.14 search and held-out validation before retaining a coefficient update.
It demonstrates the intended PS-to-PL calibration architecture but must not be
confused with ADS-trained or silicon-calibrated DPD.
