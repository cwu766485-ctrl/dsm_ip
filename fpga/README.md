# FPGA

| Path | Role |
|---|---|
| `hardware` | Local-only RFSoC 4x2 board collateral. This path is ignored for public GitHub release unless redistribution rights are confirmed. |
| `zu15eg` | Public ZU15EG PS-DMA-DSM-ILA bring-up notes and source-only helper scripts. |

The reusable IP package is generated from `rtl/ip` and `ip`. Board-specific
projects, constraints, ROM images, and captured waveforms are deliberately
excluded from the public repository.

Do not publish restricted board PDFs, schematics, BOMs, reference manuals, or
vendor board packages.
