# Cartesian DSM MATLAB Workspace

The active MATLAB workspace is:

```text
matlab/cartesian_dsm/DSM_2nd/lp
```

Start MATLAB there and run:

```matlab
path_setup
```

Use `lp/core` for algorithm and MATLAB-to-RTL closure scripts. Use `lp/paper`
for paper-facing table and figure generation. Historical exploratory scripts
from the original research dump are intentionally not part of this cleaned
handover tree.
