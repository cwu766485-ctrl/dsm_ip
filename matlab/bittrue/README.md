# P0 Bit-True Models

`p0_dsm_bittrue.m` models the registered output sequence of the seven
single-bit algorithms used by the P0 regression. `p0_compare_rtl_xsim.m`
compares the captured I/Q output dumps sample by sample and reports mismatch
counts. `entry_p0_bittrue_check.m` is the MATLAB entry point.
