# Verification Vectors

Checked-in vectors must state their producer, fixed-point format, sample count,
expected latency, and consumer. Generated simulation output belongs in ignored
`out*` directories.

- MATLAB is the algorithm and fixed-point signoff producer.
- Python is the Linux/VCS bit-exact regression producer after MATLAB equality.
- SystemVerilog testbenches consume vectors and compare RTL transactions.

Do not treat a floating-point Python waveform as an RTL golden reference.

## Checked-In Content

| Path | Producer and format | Consumer |
|---|---|---|
| `p0/rom_i.mem`, `p0/rom_q.mem` | MATLAB P0 signed I/Q ROM images | Seven DSM P0 regressions |
| `p1_64/`, `p1_256/` | MATLAB OFDM/QAM profile ROM images and metadata | Historical P1 flows |
| `memory_tinyml_*_v2.txt` | Fixed-point policy/tree vectors | C equivalence and safety tests |
| `board_*_q20.txt` | Fixed-point board replay data | Bare-metal replay scripts |

The IF/DSM block vector `bp_ef2_equivalence.csv` is generated by the Python
integer model into the ignored simulation work directory. DPD and monitor
vectors are generated by MATLAB under `matlab/out/` and are also not committed.
