# BP EFDSM2 Reference Model

Python source: `uvm_verif/refmodel/python/dsm_refmodel/bp_ef2.py`, class
`BpEf2`. The vector generator is
`uvm_verif/refmodel/python/generate_bp_ef2_vectors.py`.

The generator produces the input, bit, signed-code, and quantizer-state values
used by the block bit-true test.
