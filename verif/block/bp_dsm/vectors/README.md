# BP EFDSM2 Vectors

The block test consumes `bp_ef2_equivalence.csv`, generated by
`uvm_verif/refmodel/python/generate_bp_ef2_vectors.py`. The CSV contains input
real-IF samples, expected one-bit output, signed output, and quantizer input.
It is generated into the ignored XSim work directory so that the block test and
the IF/DSM subsystem test share one Python integer reference.
